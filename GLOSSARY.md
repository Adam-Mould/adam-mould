# adam-mould

Adam Mould's personal site. These are the terms the site's copy uses for how Adam works with AI.

## Language

**Software factory**:
A quality-controlled, agent-driven delivery workflow that spans product, design and engineering, where trust comes from verification and quality gates instead of line-by-line human review.
_Avoid_: AI pipeline, vibe coding

**Agent-ready codebase**:
A codebase with the skills, rules, architecture and static analysis that let agents, and engineers outside its specialism, ship features safely without the codebase owner in the loop.
_Avoid_: AI-friendly codebase

**Reference prototype**:
A high-fidelity, working prototype built from a spec to test whole user journeys end to end, then used as the reference for the production design and build.
_Avoid_: Throwaway prototype, spike
